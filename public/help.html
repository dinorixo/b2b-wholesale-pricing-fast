Help & Tutorials

Everything you need to configure wholesale pricing for your Shopify store.

🚀

Getting Started

Learn the basic setup process.

  1. Open Pricing Rules.
  2. Create a new pricing rule.
  3. Choose your customer group.
  4. Set the minimum quantity.
  5. Set the discount.
  6. Save and activate the rule.
Tip: Start with one simple rule before creating multiple pricing tiers.
💰

Pricing Rules

Create quantity-based wholesale discounts.

A pricing tier defines the quantity a customer must purchase to receive a discount.

  • 50+ units → 15% discount
  • 200+ units → 30% discount
  • 500+ units → 40% discount

You can create multiple tiers for different customer groups.

👥

Customer Groups

Organize customers by wholesale level.

Customer groups allow you to give different pricing to different types of customers.

  • Wholesale
  • Enterprise
  • VIP customers

Create separate rules when different groups need different discounts.

📦

Products

Control which products receive wholesale pricing.

When creating a rule, choose whether it applies to:

  • All products
  • Selected products
  • Specific product groups

This lets you keep regular retail pricing on products that shouldn't receive wholesale discounts.

📊

Analytics

Monitor how your wholesale pricing performs.

Use analytics to monitor wholesale activity and understand which pricing rules are being used.

  • Wholesale orders
  • Customer activity
  • Rule performance
  • Sales trends
❓

Troubleshooting

Quick fixes for common problems.

  1. Check that the rule is active.
  2. Check the minimum quantity.
  3. Check that the product is included.
  4. Check that the customer belongs to the correct group.
  5. Refresh the Shopify storefront and test again.
If the problem continues, check the browser console and server logs.
